# コードコメント

情報の置き場所は種類で決める。

| 置き場所 | 書くもの |
|---|---|
| コード | How (具体実装) |
| テストコード | What (仕様・振る舞い) |
| commit log | Why (変更の背景・目的) |
| コードコメント | Why-not (なぜ他の選択肢でなくこの実装か) |
| PR description / issue │ PR をまたぐ判断、依頼から外した箇所、試して捨てた案や方針転換などの経緯 |
| 仕様・設計ドキュメント │ 現在の仕様だけ。経緯は書かず、古い版を別ファイルで積まない |

コメントは既定で書かない。書くのは、消すと読み手が誤った変更をしそうなときだけにする。
たとえばWhy-not と、外部仕様・ライブラリのバグ回避など、コードからも commit log からも辿れない制約など。

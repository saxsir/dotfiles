# TDD (Test-Driven Development)

Kent Beck の TDD と和田卓人 (t-wada) の実践に従う。

## TDD サイクル

`Red → Green → Refactor` を厳密に守る。

## リファクタリング指針

- リファクタリングは Green フェーズでしか行わない
- 1 度に 1 つのリファクタリングだけを行う
- 各ステップごとにテストを再実行する
- 重複の除去・意図の明確化を優先する

## 例: 新機能を実装するときのワークフロー

1. その機能のごく小さい一部に対する失敗テストを 1 つ書く
2. 通すための最小限の実装を書く
3. テスト実行で Green を確認
4. 必要なら Tidy First で構造変更を行う（テストはそのつど実行）
5. 次の小さい増分のテストを書く
6. 機能が完成するまで繰り返す
